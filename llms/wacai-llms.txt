# Wacai (挖财)

> Wacai (挖财, Hangzhou Wacai Network Technology Co., Ltd.) is a Chinese fintech and personal-finance company founded in 2009, best known for its "挖财记账" personal accounting/bookkeeping app and internet wealth-management platform. It operates a partner-facing open API gateway ("挖财开放平台") with appKey/appSecret signed requests and official client SDKs.

## Open Platform / API Gateway
- Gateway entry: https://open.wacai.com/gw/api_entry (HTTPS POST, JSON, UTF-8; HTTP 200 ok / 400 error).
- Auth: appKey/appSecret HMAC request signing over apiName|apiVersion|headerString|bodyMd5 (headers x-wac-timestamp, x-wac-app-key/x-wac-access-token, x-wac-version).
- Operations addressed by (apiName, apiVersion), e.g. message.api.push v1.0. No public OpenAPI is published.
